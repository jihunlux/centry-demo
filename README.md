# SENTRY 웹사이트

## 실행
- `index.html`을 브라우저에서 열면 됩니다.
- `assets/sentry-product.jpg`는 메인 화면에 사용하는 사용자가 제공한 제품 사진입니다. 두 파일/폴더 구조를 유지하세요.
- 별도의 서버나 외부 라이브러리 설치는 필요하지 않습니다.

## GitHub Pages 배포
1. GitHub 저장소를 엽니다.
2. 압축을 푼 폴더 안의 `index.html`과 `assets` 폴더를 저장소 루트에 업로드합니다.
3. 변경 사항을 Commit 합니다.
4. 저장소의 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
5. 배포된 사이트 주소를 열어 확인합니다.

## 포함된 내용
- 한국어 SENTRY 랜딩 페이지와 대시보드
- 3개 히어로 슬라이드, 5초 간격 자동 전환 및 페이드 효과
- 시약 8종과 확인 필요 항목 2건의 시뮬레이션 데이터
- 검색, 시약 상세 모달, 메뉴 이동, 반응형 레이아웃

표시 데이터는 시뮬레이션이며 실제 센서 측정이나 시약 안전 판정을 제공하지 않습니다.
